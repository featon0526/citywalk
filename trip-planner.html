高德 Web 服务 key 怎么申请、接入 & 开数字签名？
  1. 高德开放平台 console.amap.com → 应用管理 → 创建应用 → 添加 key，类型选「Web 服务」。
  2. 点页面上方「⚙️ 配置高德 key」填入你的 key 并保存（存于本机浏览器 localStorage，源码不留密钥）。
  3. 刷新：景点按名称地理编码、线路调用高德真实算路，地图用 Leaflet 挂高德瓦片显示（GCJ-02 零偏移）。
  4. 开数字签名（推荐，防 key 被白嫖）：控制台该 key 点「设置」→ 开启数字签名 → 复制显示的「私钥」，在「⚙️ 配置高德 key」的私钥框里填入并保存。开启后本页每次请求自动带 sig。

① 安全（方案 B·数字签名）：私钥和 key 都仍写在前端，所以是「缓解」——能挡住随便拿 key 去别处调的人，但挡不住懂行、会读源码的人。要真根治请把 key 放后端代理（方案 A）。
② 必须配套：填了 AMAP_SIG_SECRET 就必须先在控制台「开启数字签名」，否则高德报 INVALID_USER_SCODE；反过来没填就不能开签名。
③ ToS：直接热链高德瓦片做公开产品违反高德条款，可能被限流；公开部署建议换「天地图」官方免费瓦片（需免费 tk）或回归高德 JS API。个人原型无所谓。
